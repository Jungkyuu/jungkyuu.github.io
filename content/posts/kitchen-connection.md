## Overview

Kitchen Connection is a full-stack web app I built with a team of four for our capstone project at Seneca Polytechnic. It makes it easier to find and share recipes. Users can sign in with Google or register with their own account. Once logged in, they can browse food content uploaded by other users, leave comments, and communicate with friends.

## Technologies Used

- **Next.js** – Frontend and web application development
- **MongoDB** – Database management and data storage

## Project Highlights

- Developed a full-stack web application using Next.js.
- Integrated MongoDB for database management and persistent data storage.
- Connected frontend interfaces with backend data APIs.
- Focused on creating an accessible and responsive user experience.

## What I Learned

This project gave me hands-on experience with full-stack web development and working with a NoSQL database. I also built my communication skills by coordinating schedules, holding regular meetings, and deciding with my teammates which features to build and who would take each one. Finally, I learned how the frontend and backend work together in a live, deployed site.
